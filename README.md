# Employee Data & Payroll Management System

A web-based internal human resources and automated payroll management application developed using **Core PHP Native** and **MySQL**. Designed to streamline employee record-keeping, attendance tracking, monthly salary calculations, and financial reporting.

---

> ** Project Context & Privacy Notice**
> * **Project Scope:** Developed as a University Final Project (*Tugas Talenta Unggul* / TTU) for a Bachelor of Computer Science (S.Kom) degree, using a regional financial institution as a real-world enterprise case study.
> * **Data Sanitation:** All sensitive personal data, actual salaries, and institutional identifiers have been completely removed and replaced with sanitized dummy records for public demonstration and portfolio purposes.

---

## Tech Stack & Dependencies

* **Backend Engine:** Core PHP (Native)
* **Database Management:** MySQL / MariaDB
* **Frontend UI:** HTML5, CSS3, JavaScript, Bootstrap
* **Development Server:** XAMPP (Apache)

---

## Key Features & Functionalities

* ** Multi-Role Access Control:** Separate navigation dashboards and privilege levels for `Admin` (Full Management) and `User` (Staff View).
* ** Employee Management (CRUD):** Comprehensive record tracking for staff details, job positions, employment tiers, and operational branches.
* ** Attendance & Overtime Tracker:** Logs daily check-ins, lateness calculations, and overtime hours.
* ** Automated Payroll Engine:** Dynamic salary generation incorporating basic pay, positional/family allowances, late deductions, and overtime bonuses.
* ** Payslip & Report Generation:** Direct printable outputs for individual monthly payslips and company-wide salary distribution summaries.
